# Support

## Public issues

Use a public GitHub issue for reproducible product behavior, compatibility questions, or documentation corrections that contain no sensitive information.

Include:

- Mac family, without a serial number;
- macOS version;
- MacBaram version;
- affected feature;
- steps to reproduce;
- expected and observed behavior.

Do **not** include names, email addresses, account identifiers, serial numbers, device identifiers, payment details, license data, access tokens, private file paths, full logs, or raw diagnostic archives.

## Private support

For account, payment, license, or diagnostic matters, email [support@macbaram.com](mailto:support@macbaram.com). Send only the minimum information needed. Support may request a specific, sanitized diagnostic excerpt through a private channel.

## Security reports

Do not open a public issue for a vulnerability or suspected security incident. Follow [SECURITY.md](SECURITY.md).
