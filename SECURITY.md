# Security policy

Please report suspected vulnerabilities privately to [support@macbaram.com](mailto:support@macbaram.com) with the subject `MacBaram security report`.

Include a concise description, affected version, reproduction conditions, and impact. Do not send credentials, private keys, access tokens, unrelated personal data, or a full device diagnostic archive. If sensitive evidence is necessary, first ask for a suitable private transfer method.

Do not publish the report in a GitHub issue, discussion, social post, or third-party tracker. Please allow reasonable time for validation and remediation before public disclosure.

This policy does not authorize access to another person's device or account, disruption of services, social engineering, persistence, data extraction, or testing against production data.
